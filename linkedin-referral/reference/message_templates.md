# Message templates

Fill `<…>` from the résumé and the job description. Pick the 1–2 résumé facts
that best match the JD's top requirements. Count characters for connection
notes — LinkedIn rejects anything over 300.

## Connection note — hiring manager / senior engineer (≤ 300 chars)

```
Hi <FirstName>, I'm a <CurrentTitle> at <CurrentCompany> building <1 matching fact>. I saw the <Role> opening (<JobId or short link>) on your team and think my <skill> fits well. Would you be open to a referral? Happy to share my résumé.
```

Shorter variant:

```
Hi <FirstName>, <CurrentTitle> at <CurrentCompany> here — <matching fact>. Applying for <Role> at <Company>; would you consider referring me? Can send résumé + summary. Thanks!
```

## Connection note — recruiter (≤ 300 chars)

```
Hi <FirstName>, I'm interested in the <Role> role at <Company>. I have <N> yrs in <domain> (<matching fact>) and am open to <Remote/Hybrid, City>. Could I share my résumé with you?
```

## Connection note — alumni hook (only if true)

```
Hi <FirstName>, fellow <School> alum here (<Degree>, <Year>). I'm a <CurrentTitle> at <CurrentCompany> and applying for <Role> at <Company>. Would you be open to referring me? Glad to send details.
```

## Message after connect accepted / 1st-degree (≤ ~700 chars)

```
Thanks for connecting, <FirstName>!

I'm applying for <Role> at <Company> (<job link>). Quick fit:
• <résumé fact matching requirement 1>
• <résumé fact matching requirement 2>
• <education / publication / years, if relevant>

If you're comfortable referring me, I can send my résumé and a 2-line summary for the referral form. Totally understand if not — thanks either way!
```

## Follow-up (no reply after 4–5 days, send once)

```
Hi <FirstName>, just bumping this in case it got buried — still keen on the <Role> role. Happy to make it easy with a ready-to-paste summary. Thanks!
```

## Referral pack (send when someone agrees)

```
Name: <Full name> | Email: <email> | Phone: <phone>
Role: <Role> — <job link / ID>
Current: <Title>, <Company> (<start>–present), <N> yrs total
Summary: <2 lines: what you build + strongest matching result>
Résumé: attached
```

## Don'ts

- No generic "Please refer me for any role".
- No attachments or links in the first note except the job link.
- No flattery you can't back up, no invented metrics.
- Never message the same person twice in one week.
